# Object tracking

Understand and implement AR Foundation object tracking.

Object tracking allows your app to detect and track 3D objects in the physical environment. The [AR Tracked Object Manager](xref:UnityEngine.XR.ARFoundation.ARTrackedObjectManager) component controls object tracking functionality in your app, and creates [ARTrackedObject](xref:UnityEngine.XR.ARFoundation.ARTrackedObject) trackables for each detected object.

You can use object tracking in your app to create interactive experiences that blend real-world and digital content. For example, guided instructions, product demos, training overlays, and object-based gameplay.
